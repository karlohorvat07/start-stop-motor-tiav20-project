🛗 Start/Stop Motor with Fault Reset — Siemens TIA Portal

A Motor control system created as a personal project while independently learning PLC programming and industrial automation with Siemens TIA Portal.

📖 Project Overview

The project simulates the basic operation of a classic Electro-Motor controlled by a Siemens PLC.

The PLC handles Start/Stop, Fault Reset, Active Faults and Motor.

The goal of this project was to practice creating a complete control sequence rather than programming individual PLC exercises.

⚙️ Main Functions 
Make motor work, but when fault is active the motor is turned off until the fault is reseted/acknowledged

🧠 What I Learned

While developing this project, I practiced:

PLC programming with Siemens TIA Portal Creating sequential control logic Working with digital inputs/outputs and memory bits. (Coils, Contatcs....)

Most importantly, this project helped me understand how multiple PLC conditions and sequences work together as one automated system.

🛠 Software Siemens 
TIA Portal v20 
PLCSIM v20

🎯 Purpose

This project was created independently as part of my self-learning in PLC programming and industrial automation.

It is an educational project and is not intended to control a real passenger elevator or safety-critical system.
